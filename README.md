# ひと息 — Visual Focus Timer

スマホ向けの視覚タイマー。時計一周を30・60・90・120分に変更でき、赤い扇形が残り時間に応じて減ります。1分刻みのプルダウン選択、集中／休憩、停止・再開、終了音、状態の端末保存に対応。横向きは左右、縦向きは上下のレイアウトです。

## 開発

依存パッケージ・ビルド不要。`python3 -m http.server 8080` で配信し、ブラウザで開いてください。ロジックテストは `npm test`。

## GitHub Pages

`main` ブランチのルートをGitHub Pagesの公開元に設定します。アプリには秘密情報や外部サービスへのデータ送信はありません。設定と計測状態はブラウザのlocalStorageに保存されます。

## スマホの制約

ホーム画面への追加に対応。画面が表示されている間は対応端末でScreen Wake Lockを要求します。OSにより背景・ロック中の音は保証されません。タイマーは終了時刻から計算するため、復帰時は正しい残り時間を表示します。オフライン利用は保証しません。複数タブや端末間の同期はしません。
